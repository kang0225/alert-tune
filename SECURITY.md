# Security Policy

## Supported versions

alert-tune is in early development. Security fixes target the `main` branch; older commits and release lines are not maintained separately.

## Reporting a vulnerability

Email the maintainer at [kjskkdkmj@gmail.com](mailto:kjskkdkmj@gmail.com) with the subject `[alert-tune] Security report`.

Please include:

- The affected version or commit.
- A description of the issue and its potential impact.
- Minimal steps or a sanitized example that reproduces the issue.
- A suggested fix, if you have one.

Do not disclose vulnerability details in a public issue or pull request. Do not send live credentials or sensitive production data.

There is currently no fixed response or remediation timeline. Please coordinate disclosure privately with the maintainer.
